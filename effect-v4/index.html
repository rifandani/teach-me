Effect v4, from the mental model up

Eight short lessons to help you decide, with evidence, whether Effect is worth adopting.

The mission

By the end you can read real v4 code, rebuild a small service with typed errors, dependency injection and a swappable test layer, spot outdated v3 tutorials, and write a one-page adopt / pilot / skip recommendation for your team. (MISSION.md)

  2. Why not plain TypeScript?The problems Effect solves, and the first draft of your cost ledger.

  8. The verdict: should your team adopt Effect?Incremental adoption, risk facts, and your written recommendation.

How each lesson works

Each lesson lives in its own folder under lessons/ and has four parts.

  • index.html: the lesson, with a warm-up on earlier lessons, an in-browser quiz and citations to the primary sources.
  • exercise.ts: small tasks that check themselves.
  • solution.ts: reference answers.
  • tsconfig.json: runs the type-level checks for that lesson.

One-time setup, from this effect-v4/ folder (needs Node 22.18 or newer):

npm install

Then, for lesson NN:

node lessons/01-mental-model/exercise.ts      # runtime checks
npx tsc -p lessons/01-mental-model            # type-level checks

Reference

  • Cheat sheet: the core v4 API on one printable page.
  • Spotting v3 code: old name → v4 name, for when a tutorial or an LLM gives you outdated code.
  • RESOURCES.md: annotated primary sources and the official community.
  • research/effect-v4.md: the full research notes behind this course, with every claim cited and every snippet run against 4.0.0.
