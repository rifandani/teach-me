Spotting v3 code

Most Effect tutorials, Stack Overflow answers and LLM output online were written for v3. If you see a name from the left column, translate it.

The three-second test

If the code contains Context.Tag, Effect.Service, catchAll, Either, Effect.fork or @effect/platform, it is v3. If it contains ServiceMap.Service or effect/unstable/…, it comes from a v4 beta and is also outdated.
