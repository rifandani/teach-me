Effect v4 cheat sheet

The core API on one page. Print it, or keep it open in a tab while you write code.

The type (L1)

Effect.Effect<A, E = never, R = never>
//           success  error   requirements

Effect.Success<typeof e>   // A
Effect.Error<typeof e>     // E
Effect.Services<typeof e>  // R   (v3: Effect.Context)

An Effect is a lazy, immutable description. Nothing runs until you run it at the edge.

Run at the edge (L1)

Effect.runSync(e)          // value, or throws
Effect.runPromise(e)       // Promise; rejects with the raw error
Effect.runSyncExit(e)      // Exit, never throws
Effect.runPromiseExit(e)   // Promise<Exit>
Effect.runFork(e)          // Fiber
NodeRuntime.runMain(e)     // @effect/platform-node: signals, exit codes
// every runner requires R = never

Create (L3)

Effect.succeed(a)a value you already have
Effect.fail(e)an expected error
Effect.sync(() => …)sync side effect that won't throw
Effect.try({ try, catch })sync code that may throw
Effect.promise(() => p)Promise that never rejects
Effect.tryPromise({ try, catch })Promise that may reject
Effect.callback(resume => …)callback API (v3: async)
Effect.fromNullishOr(x)nullable value

Compose (L3)

Effect.gen(function*() {
  const user = yield* findUser(id)        // like await
  if (!user.ok) return yield* new NotFound({ id })
  return user.name
})

const f = Effect.fn("f")(function*(x: number) { … },
  Effect.catchTag("E", …))     // extra args = combinators

e.pipe(
  Effect.map((a) => …),        // pure transform
  Effect.flatMap((a) => eff),  // next Effect
  Effect.tap((a) => Effect.log(a)),  // must return an Effect (v4)
  Effect.andThen((a) => eff)   // Effect or fn → Effect only (v4)
)

Errors (L4)

class NotFound extends Data.TaggedError("NotFound")<{
  readonly id: number
}> {}

e.pipe(Effect.catchTag("NotFound", (err) => …))   // removes it from E
e.pipe(Effect.catchTag(["A", "B"], (err) => …))
e.pipe(Effect.catchTags({ A: …, B: … }))
e.pipe(Effect.catch((err) => …))        // v3: catchAll
e.pipe(Effect.mapError((err) => …))
e.pipe(Effect.orDie)                    // expected error → defect
e.pipe(Effect.catchDefect((d) => …))    // boundary only
e.pipe(Effect.catchCause((cause) => …))
e.pipe(Effect.result)                   // Effect<Result<A, E>> (v3: either)

Expected error: typed and in E; recover from it. Defect: a bug, kept only in Cause (cause.reasons: Fail | Die | Interrupt).

Services & Layers (L5)

class Db extends Context.Service<Db, {
  readonly query: (sql: string) => Effect.Effect<Rows>
}>()("app/Db") {
  static readonly layer = Layer.effect(Db, Effect.gen(function*() {
    const config = yield* Config        // layer's own needs
    return Db.of({ query: (sql) => … })
  })).pipe(Layer.provide(Config.layer))
}

const program = Effect.gen(function*() {
  const db = yield* Db                  // R = Db
  return yield* db.query("select 1")
})
program.pipe(Effect.provide(Db.layer))   // R = never
program.pipe(Effect.provideService(Db, fakeDb))
Layer.succeed(Tag, impl)layer from a value
Layer.effect(Tag, eff)from an Effect (scoped resources too)
Layer.provide(dep)feed dep in, hide it
Layer.provideMerge(dep)feed dep in, keep it in the output
Layer.merge(a, b)side by side

Conventions: X.layer, X.layerTest. Service methods should have R = never.

Resources (L6)

const file = Effect.acquireRelease(
  open("a.txt"),
  (handle, exit) => close(handle)       // always runs
)                                        // R includes Scope
Effect.scoped(program)                   // closes the scope at the end
// finalizers run in reverse order on success, failure or interruption

Concurrency (L6)

Effect.all([a, b, c])                          // sequential by default!
Effect.all([a, b, c], { concurrency: 2 })
Effect.forEach(ids, fetch, { concurrency: "unbounded" })
Effect.race(a, b)                              // loser is interrupted

const fiber = yield* Effect.forkChild(task)     // v3: fork
const value = yield* Fiber.join(fiber)          // fibers aren't Effects in v4
yield* Fiber.interrupt(fiber)

Timeouts & retries (L6)

e.pipe(Effect.timeout("1 second"))      // E | Cause.TimeoutError
  .pipe(Effect.catchTag("TimeoutError", () => fallback))

e.pipe(Effect.retry({ times: 3 }))
e.pipe(Effect.retry(Schedule.max([           // all must continue
  Schedule.exponential("100 millis"),
  Schedule.recurs(5)
])))
// Schedule.min([...]) = any continues;  Schedule.concat = one then the other

Schema (L7)

import { Schema } from "effect"

const User = Schema.Struct({
  id: Schema.Int,
  name: Schema.String.check(Schema.isMinLength(1)),
  role: Schema.Literals(["admin", "member"]),
  nickname: Schema.optional(Schema.String)
})
type User = typeof User.Type

Schema.decodeUnknownSync(User)(input)     // throws
Schema.decodeUnknownEffect(User)(input)   // fails with SchemaError
Schema.decodeUnknownSync(Schema.fromJsonString(User))(json)

Config & logs (L7)

const port = yield* Config.Int("PORT").pipe(Config.withDefault(3000))
const key  = yield* Config.Redacted("API_KEY")   // prints <redacted>
// tests: Effect.provide(ConfigProvider.layer(ConfigProvider.fromUnknown({ PORT: 8080 })))

yield* Effect.log("hello")       // also logInfo, logWarning, logError, logDebug
Effect.withSpan("name")          // tracing span; Effect.fn("name") adds one

Embed in existing code (L8)

// a plain async function / route handler
async function handler(req) {
  return Effect.runPromise(program.pipe(Effect.provide(AppLayer)))
}
// share services across many handlers: ManagedRuntime.make(AppLayer)
